## Summary
An interactive Python application bridging text generation with music streaming. Users input an aesthetic mood prompt, and a Large Language Model dynamically synthesizes matching track data before constructing a live playlist in their Spotify account.

# 🎵 AI-Powered Spotify Vibe Playlist Generator
Building AI course project

## Tech Stack
- **Python 3**
- **OpenAI API**
- **Spotipy Library**

## Setup Instructions
1. Clone this repository.
2. Install dependencies: `pip install openai spotipy python-dotenv`
3. Create a `.env` file with your credentials (`SPOTIPY_CLIENT_ID`, `SPOTIPY_CLIENT_SECRET`, `SPOTIPY_REDIRECT_URI`, `OPENAI_API_KEY`).
4. Run `python app.py` and paste your desired mood!
